# 📝 Todo List

Aplicación **Full Stack** para gestionar y organizar tareas de forma sencilla por carpetas (proyectos) asignando prioridad, fechas de vencimiento y estados, 
además de un apartado para agregar y gestionar notas individuales.

Diseñada con una interfaz **moderna, intuitiva y responsive**.

## 🚀 Stack

**Frontend**

* React + Vite
* Tailwind CSS
* React Router
* Framer Motion
* Arquitectura basada en **Features + componentes reutilizables**

**Backend**

* Node.js + Express
* PostgreSQL
* REST API
* ES Modules
* Arquitectura basada en **módulos por funcionalidad**

## ✨ Características

* ✅ Gestión completa de tareas
* 📁 Organización por carpetas
* 🎯 Prioridades y estados
* 📅 Fechas de vencimiento
* 🔎 Búsqueda y filtros
* 📱 Diseño responsive
* 🔐 Autenticación y validación de datos

## 🏗️ Estructura

```text
todo-list/
├── frontend/   # React · Features + UI components
└── backend/    # Node.js · Módulos por funcionalidad
```
